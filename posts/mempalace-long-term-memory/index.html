AI 的记忆宫殿：MemPalace 给大模型补上丢失的那片记忆

发表于2026-10-20|更新于2026-10-20|技术分享
|总字数:1.8k|阅读时长:5分钟

跟 AI 聊了一整天，方案改了三轮，坑踩了两个，临到傍晚它突然蹦出一句客气又茫然的”好的，我们接下来做什么？”——几小时的对话像被人从脑子里整块挖掉，你还得耐着性子把背景再喂一遍。

这不是哪个模型笨，是所有大模型都撞在同一堵墙上：上下文窗口就那么长，聊满了就得往后倒。 MemPalace 就是冲着这堵墙来的。它不是又一个聊天机器人，而是塞在你本地、专门替 AI 记账的那间档案室。

项目仓库：github.com/MemPalace/mempalace，最早那个 milla-jovovich/mempalace 旧地址现在会自动跳转到这儿，没删也没归档，最近一次代码推送是 2026 年 10 月 18 日。

它到底是个什么东西

一句话：把你跟 AI 说过的话一字不差地存下来，要用的时候再按语义捞回来，全程不出你的电脑。

仓库自己的说法很克制——“Local-first AI memory. Verbatim storage, pluggable backend, 96.6% R@5 raw on LongMemEval — zero API calls.” 拆开看是三个关键词。

Verbatim，原样留存。 这是它跟大多数记忆方案最不一样的地方。市面上很多记忆库爱干”摘要”这件事，把你三页对话压成两段要点存进向量库。可摘要天然会丢东西：比喻、临场想到的岔路、那句”等等我再想想”往往先被删掉。MemPalace 不替你概括，原文进、原文出，它只负责给原文找个好抽屉。

Local-first，本地优先。 不强制联网、不调云端接口、不上传对话。装完它，所有东西落在你自己机器上——这点对要聊商业方案、客户资料、内部代码的人来说分量很重。

零 API 调用。 检索这一步不花钱、不烧 token，靠本地向量模型做语义匹配。

跑分这块，README 列得很实，也没吹满：

  • 行业常用的 LongMemEval 长记忆测试里，纯语义检索、不过任何启发式、不需要大模型参与，R@5 是 96.6%；
  • LoCoMo 数据集，原始模式 R@10 60.3%，走 hybrid v5 混合检索到 88.9%；
  • ConvoMem 全套目平均召回 92.9%。

💡 这些数字不是嘴上说说，仓库的 benchmarks/ 目录里放了命令，你可以自己跑一遍复现。

记忆宫殿，是怎么个”宫殿”法

名字不是白叫的，它的索引真按一座房子分层，而不是平铺在一整个大仓库里瞎捞：

  • Wing（翼）：最大的分区，一个人、一个项目占一翼；
  • Room（房间）：翼里再按话题分室，比如架构、选型、踩过的坑；
  • Drawer（抽屉）：真正的原始对话、原始文件躺在抽屉里，检索先定位到翼、再进房间，范围缩得小，命中自然准。

这么设计的好处是，你搜东西不必死守当初分类时用的那个词。 模糊记得”咱们聊过那个想法”，但说不上关键词，普通关键词工具就够不着，靠语义在缩小后的范围里找才捞得回来。

谁做的、靠不靠谱

2026 年 4 月这个项目确实刷过屏，话题一度是 #好莱坞演员 vibecoding#，爱范儿、36 氪、游民星空都以”《生化危机》女主开源 AI 记忆系统”为题做过报道。

按项目自己的说法，仓库署名 Milla Jovovich，自述是 Creator/Architect，讲自己被 Claude 的上下文窗口折磨，才动手研究各种记忆系统；工程师 Ben Sigman 搭后端，目前仓库里绝大多数提交和合并由维护者 Igor Lins e Silva 完成。

⚠️ 这里留一句实在话：上面这些多是二手转述，源头是 GitHub 账号自述，我没有抓到演员本人官方账号的原始声明。“账号背后就是那位女演员本人”这一层，建议你自己掂量，别仅凭一个 GitHub 简介就钉死。

另外提醒一句，网上一堆 mempalace.tech / .info / .net 之类的站点是 README 自己警告过的仿冒镜像，里面”100% 满分””48 小时 19000 星”彼此打架，别信，也别从它们那儿下载。一切以官方仓库和官网 mempalaceofficial.com 为准。

它主要帮你扛哪几件事

把抽象功能落到具体场景，它主要解决四件烦事：

  • 长对话不断片。 一个项目跨几天、几周，AI 不用每次重新认识你。上个月定的技术选型、为什么否决了另一个方案，新开会话直接调出来接着聊。
  • 个人和项目知识库。 代码、文档、Claude / ChatGPT / Slack 的历史对话都能导进来，变成一个可语义搜索的本地档案，找”当时那个接口怎么定的”不用翻聊天记录往上爬楼。
  • 给 AI 代理配持久记忆。 接上 MCP 之后，你编程时它自动先翻记忆再回答，不用手动复制粘贴上下文。仓库一共挂着 47 个 MCP 工具，覆盖宫殿读写、知识图谱、跨翼导航、抽屉管理这些操作。
  • 隐私敏感的活儿。 客户沟通、报价、未公开代码，全程留在本机，不经过任何第三方。

门槛不高，会敲命令就行。环境要求 Python 3.10 以上。第一次用会下载本地向量模型：推荐多语言的 embeddinggemma（约 300MB，支持 100 多种语言）；只做英文也可以用轻量的 minilm（约 30MB）。

几句实在的判断

截至 2026 年 10 月 20 日，这个仓库约 5.9 万 Star、7.5k Fork，MIT 协议可自由商用修改，还在活跃更新。它不是什么黑科技，本质就是 “原样存储 + 结构化索引 + 本地语义检索” 这一套组合拳，胜在不摘要、不出本机、跑分可复现。

作者自己也留了句老话：这是新工具，别一上来就拿关键文件试，先拿点无关紧要的东西跑通，再把整套数据搬进去。

MemPalace 是一个本地优先、原文留存、零 API 调用的开源 AI 长期记忆库，用”翼—房间—抽屉”的记忆宫殿结构给大模型续上长记忆，几行命令就能把历史对话变成可语义搜索的私人档案。

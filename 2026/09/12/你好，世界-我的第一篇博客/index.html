你好，世界！

这是我用 Hexo 搭建的个人博客的第一篇文章。

为什么要写博客？

  • 记录学习和思考的过程
  • 分享知识，帮助他人
  • 倒逼自己输出和总结

这个博客用了什么？

  • 框架：Hexo - 快速、简洁、高效的博客框架
  • 主题：Butterfly - 简洁美观的主题
  • 托管：GitHub Pages - 免费、稳定

接下来会写什么？

  • 技术学习笔记
  • 生活感悟
  • 实用工具分享
  • 读书心得

路漫漫其修远兮，吾将上下而求索。

感谢你的访问，欢迎常来！

我的技术学习路线图学习技术是一场马拉松，不是百米冲刺。以下是我为自己规划的学习路线。 第一阶段：打好基础编程语言 Python：入门友好，生态丰富 JavaScript：前端必备，全栈基础 计算机基础 数据结构与算法 计算机网络 操作系统 第二阶段：方向深耕前端方向 HTML / CSS / JavaScript 深入 React / Vue 框架 工程化工具链 后端方向 Node.js / Go / Java 数据库（MySQL / MongoDB） 容器化与部署 第三阶段：进阶提升 系统设计与架构 性能优化 开源项目贡献 学习方法建议 动手实践：每学一个知识点，都要写代码验证 输出倒逼输入：写博客、做笔记，教会别人才算学会 保持节奏：每天学习 1-2 小时，胜过周末突击 8 小时 种一棵树最好的时间是十年前，其次是现在。 加油，一起进步！

OpenClaw Windows 完整安装教程（云端AI + 本地AI）

最强小白指南：OpenClaw Windows 完整安装教程（云端AI + 本地AI 一次讲透）

很多人第一次接触 OpenClaw 时，都会遇到几个问题：

  • 网上教程太复杂，看不懂
  • 安装到一半就报错
  • 不知道该用云端 AI 还是本地 AI
  • 一堆命令不知道在干什么

这篇文章就是为完全没有技术基础的新手写的。只要照着一步一步做，基本都可以成功安装。

本教程包含：

  • Windows完整安装流程
  • 云端AI配置
  • 本地AI配置
  • 常见错误解决
  • 新手最推荐配置

整个流程分为6大步骤：

  1. 检查电脑环境
  2. 安装基础软件
  3. 安装 OpenClaw
  4. 配置 AI（云端 或 本地）
  5. 启动 OpenClaw
  6. 解决常见问题

一、OpenClaw 是什么？

简单理解：

OpenClaw = AI 控制中心

它本身不是 AI 模型，而是用来连接 AI 并执行任务。

比如：

  • 调用 ChatGPT
  • 调用 Gemini
  • 调用本地大模型
  • 自动执行任务
  • 连接 Telegram / Discord

你可以把它理解为：AI大脑 + 自动执行工具

二、OpenClaw 的两种 AI 使用方式

OpenClaw 可以连接两种 AI。

1. 云端 AI（推荐新手）

AI 在互联网服务器运行。

常见：OpenAI、Google Gemini、Minimax

优点：最聪明、不占电脑性能、设置简单
缺点：需要 API Key、有些需要付费

2. 本地 AI

AI 运行在你的电脑上。

常见工具：Ollama

优点：完全免费、不联网也能用、数据私密
缺点：吃电脑配置、回答能力略弱

三、安装前电脑要求

最低配置建议：

项目 建议配置
系统 Windows 10 / Windows 11
内存 8GB以上
硬盘 至少30GB
网络 稳定网络

如果要运行本地AI，建议：16GB内存、RTX3060 或以上显卡。

四、安装基础环境（必须安装）

OpenClaw 需要三个基础工具：Node.js、Git、PowerShell权限。

1. 安装 Node.js

Node.js 是 OpenClaw 的运行环境。

  • 打开官网：https://nodejs.org
  • 点击 LTS (Recommended for most users)
  • 下载 Windows 版本
  • 双击安装包，一直 Next → Install
  • 检查安装：Win+R → 输入 powershell → 输入 node -v，看到版本号即成功

2. 安装 Git

Git 用来下载程序。

  • 打开：https://git-scm.com
  • 点击 Download for Windows
  • 双击安装包，全部默认 Next → Install

3. 解除 PowerShell 限制

Windows 默认禁止运行脚本，需要开启权限。

  • 搜索 PowerShell，右键以管理员身份运行
  • 输入命令：Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  • 按回车，输入 Y 确认

七、方案一：使用云端AI（推荐）

如果你电脑配置一般，推荐用云端AI。

以 Google AI 为例：

  1. 打开 https://aistudio.google.com
  2. 登录账号，创建 API Key，复制 Key
  3. 在初始化向导中选择 Provider → Google AI
  4. 粘贴 API Key 即可完成配置

八、方案二：使用本地AI（完全免费）

如果你想不花钱、本地运行、不联网，可以用 Ollama。

  1. 打开 https://ollama.com，下载 Windows 版本安装
  2. 安装后系统托盘会出现 Ollama 图标
  3. 打开 PowerShell，输入：ollama pull qwen2.5:7b（模型约4GB）
  4. 重新运行 openclaw onboard --install-daemon
  5. 选择 Provider → Ollama，URL 填 http://localhost:11434，API Key 随便写或留空

十一、常见问题解决

1. 命令无法识别

报错：openclaw is not recognized
解决：关闭 PowerShell，重新打开再运行命令。

2. npm install 失败

出现 node-gyp error，原因是缺少 C++ 编译工具。
解决：安装 Visual Studio Build Tools，安装时勾选 Desktop development with C++。

3. Ollama 无法连接

报错：Disconnected from gateway
解决：输入 ollama serve 重新启动。

4. 网页打不开

OpenClaw网关没有运行，输入：openclaw gateway restart

5. 自动检测问题

如果不知道哪里出错，输入：openclaw doctor，系统会自动检查问题。

十二、关闭和升级

  • 关闭：openclaw gateway stop
  • 升级：npm install -g openclaw@latest

十三、新手最推荐配置

如果你是第一次使用，推荐：OpenClaw + 云端AI

原因：安装简单、不吃电脑配置、AI更聪明。

等熟悉之后再尝试 OpenClaw + Ollama 本地AI。

最后总结

整个安装流程其实只有三件事：

  1. 安装基础环境
  2. 安装 OpenClaw
  3. 选择 AI（云端 或 本地）

只要按顺序操作，大多数人10分钟内可以完成安装。

如果你继续深入使用 OpenClaw，下一步可以研究：自动任务执行、AI代理、Telegram机器人、Discord机器人、AI自动化工作流等功能。
